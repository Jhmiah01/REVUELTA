# ♻️ Revuelta Mendoza - Sitio Web Institucional

Bienvenido al repositorio oficial del sitio web de **Revuelta**, un proyecto mendocino enfocado en la economía circular, el reciclaje de residuos tecnológicos y la donación de equipamiento reacondicionado.

---

## 📌 Sobre el Proyecto

Muchas personas conservan dispositivos electrónicos en desuso durante años por no saber qué hacer con ellos. Este sitio web surge para dar respuesta clara a las dudas más frecuentes de la comunidad, reduciendo el tiempo de atención individual por mensajería y generando un canal transparente y confiable.

### 🎯 Objetivos de la Plataforma:
* **Explicar el modelo de trabajo:** Cómo funciona el proceso de recepción, evaluación, reparación y reciclaje de hardware.
* **Transparencia y Seguridad:** Detallar el procedimiento de borrado seguro de datos personales en discos y memorias.
* **Ubicación y Canales Directos:** Ofrecer la dirección del local físico (Calle Entre Ríos 158, Mendoza) y acceso directo a WhatsApp e Instagram.
* **Catálogo Informativo:** Presentar los productos reacondicionados disponibles para consulta presencial o vía WhatsApp.
* **Formulario de Consultas:** Facilitar la coordinación para entregas en local o solicitudes de retiro a domicilio.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica, formularios, maquetación de secciones y navegación interna mediante anclas (`#id`).
* **CSS3:** Diseño personalizado siguiendo la paleta de colores corporativa (`#DCF6B8`, `#3CA20E`, `#08592C`, `#152B2A`, `#F5F3EA`) e implementación de **Flexbox** para la disposición horizontal del catálogo.
